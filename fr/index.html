Des migrations de bases de données sans surprises.

Ptah compare le schéma souhaité à une base existante, puis génère des migrations versionnées ou applique un plan approuvé. Il migre aussi l’état d’inférence persistant, par exemple pour recalculer les embeddings d’une table pgvector. PostgreSQL, MySQL, MariaDB, SQLite et d’autres moteurs. Open source, licence MIT, sans chaîne de compilation à installer.

Des tâches courantes au fil de la semaine.

        
De vraies commandes et leurs sorties réelles. Les codes de retour sont constants : 0 en cas de succès, 1 pour un contrôle négatif, 2 pour une erreur d’utilisation ou de connexion.

      

      

        

          

            
01 · Contrôler une pull request

            
Faire échouer la CI en cas de dérive du schéma ou de migration risquée.

          

          
$ ptah migrations lint --dir ./migrations \
    --dialect postgres
No lint findings.
$ ptah schema drift \
    --schema-file schema.sql \
    --db-url "$PTAH_DATABASE_URL"
No schema drift detected.

          
Ou utilisez uses: stokaro/ptah-action@v1 : l’Action publie le plan dans la pull request et crée un contrôle des modifications destructives.

        

        

          

            
02 · Sceller un répertoire de migrations

            
Refuser un fichier de migration modifié après la revue.

          

          
$ ptah migrations hash --dir ./migrations
Wrote ./migrations/ptah.sum
2 migration file(s) hashed
$ ptah migrations status \
    --db-url sqlite://app.db \
    --migrations-dir ./migrations
Current Version: 1700000000
Total Migrations: 1
Applied Migrations: 1
Pending Migrations: 0

          
ptah.sum conserve une somme de contrôle par fichier. Les commandes suivantes la vérifient avant toute exécution.

        

        

          

            
03 · Changer de modèle d’embeddings

            
Recalculer les embeddings d’une table pgvector et conserver les anciens vecteurs jusqu’à la vérification.

          

          
ptah inference plan
ptah inference prepare
ptah inference backfill
ptah inference catchup
ptah inference index
ptah inference verify
ptah inference cutover
ptah inference rollback · retire

          
Ptah construit la nouvelle génération à côté de la génération active, appelle votre service d’embeddings compatible OpenAI et vérifie le résultat. Il fait basculer les requêtes à votre demande. Il ne calcule aucun vecteur lui-même.

        

      

    

  


  

    

      

        
Travaille avec vos schémas existants.

        
Chaque source est convertie dans le même schéma interne avant la planification. --schema-file et --root-dir peuvent être répétés et combinés. Le résultat fusionné est le schéma souhaité. Aucun format propriétaire n’est requis.

        

          
--schema-file
SQL, YAML, HCL, DBML

          
--root-dir
Structs Go annotées

          
--schema-cmd
Un programme qui produit du SQL, HCL ou YAML, par exemple un exporteur ORM

          
--db-url
Une base existante, convertie en modèles Go par ptah introspect

        

      

      
schema.sql · models/*.go · base existante
        │
        ↓
      ptah  valider → planifier → analyser → appliquer → dérive
        │
        ↓
     base de données
