Communauté

Ptah est développé ouvertement sur GitHub. Questions, idées, rapports de bugs et contributions sont les bienvenus, quelle que soit votre expérience des bases de données ou de Go.

La participation est encadrée par le code de conduite.

Poser une question

GitHub Discussions accueille les questions sur ptah, ptah-compat ou la bibliothèque Go, les idées qui ne sont pas encore des demandes de fonctionnalités précises et les projets réalisés avec Ptah. La lecture est publique ; la publication exige un compte GitHub.

La FAQ et la page de dépannage répondent aux questions fréquentes. Cherchez d’abord dans la documentation. Si une réponse résout votre problème, marquez-la comme solution pour les lecteurs suivants.

Poser une question dans Q&A → Parcourir les discussions

Signaler un bug

Les bugs et demandes de fonctionnalités vont dans le suivi des issues, avec une étiquette et une personne responsable. Les formulaires demandent la commande exacte, la sortie de ptah version, le moteur et sa version, ainsi que l’entrée minimale reproduisant le problème. Précisez le binaire utilisé : ptah et ptah-compat exposent volontairement des commandes différentes.

Les problèmes de l’opérateur Kubernetes relèvent de stokaro/ptah-operator, et ceux de ce site de stokaro/ptah.run.

Ouvrir une issue → Rechercher parmi les issues

Signaler une vulnérabilité

Signalez les problèmes de sécurité en privé via le formulaire d’avis de sécurité GitHub, plutôt que dans une issue ou une discussion. Seuls vous et les responsables du projet voyez le rapport jusqu’à la publication d’un avis.

Contribuer

Le code est une façon de contribuer. Un cas de reproduction minimal, une mesure sur un véritable serveur, une correction de documentation ou une réponse dans Discussions sont aussi utiles. CONTRIBUTING.md décrit les propositions de modification et les vérifications requises. AGENTS.md contient les règles de travail appliquées par la CI. Les deux documents sont en anglais.

Ouvrez une issue avant de modifier un comportement afin de convenir de la conception avant l’implémentation.

Dépôts

Ptah comprend plusieurs dépôts de l’organisation stokaro. Chacun reçoit ses propres issues et pull requests.

stokaro/ptah
Les binaires ptah, ptah-compat et ptah-ls, la bibliothèque Go et la documentation en anglais sur docs.ptah.run.
stokaro/ptah-operator
L’opérateur Kubernetes. Son guide en anglais est sur operator.ptah.run.
stokaro/ptah-action
La GitHub Action : planification des migrations, analyse statique, commentaires de pull request et contrôles des modifications destructives.
stokaro/ptah-testkit
Des outils de test pour les projets qui intègrent Ptah, importés via ptah.run/testkit.
stokaro/ptah-sandbox
Le bac à sable : la CLI compilée en WebAssembly, exécutée avec une véritable base SQLite dans le navigateur.
stokaro/homebrew-ptah
Le tap Homebrew utilisé par brew install stokaro/ptah/ptah.
stokaro/ptah.run
Ce site web.

Assistance commerciale

Pour les demandes commerciales, écrivez à l’adresse indiquée dans la FAQ. Conservez les rapports de bugs et les demandes de fonctionnalités dans le suivi public des issues.
