Ptah installieren

Das Installationsskript lädt das Archiv für Ihr Betriebssystem und Ihre Architektur herunter, prüft die SHA-256-Prüfsumme und installiert ptah, ptah-compat und ptah-ls ohne Administratorrechte.

Aktuelles Release v0.3.0 · pre-GA: Die native Befehlsstruktur und die öffentliche Go-API können sich noch ändern · MIT

macOS
$ curl -fsSL https://ptah.run/install.sh | sh

Installiert nach ~/.local/bin. Erfordert ein Terminal, tar und curl. Auch Homebrew ist möglich: brew install stokaro/ptah/ptah. Laden Sie Archive mit curl oder gh herunter. Browser-Downloads tragen ein Quarantäneattribut, wegen dem Gatekeeper die ad hoc signierten Programme ablehnt.

Linux
$ curl -fsSL https://ptah.run/install.sh | sh
# ohne curl
$ wget -qO- https://ptah.run/install.sh | sh

Installiert nach ~/.local/bin. Archive: ptah_0.3.0_linux_amd64.tar.gz, ptah_0.3.0_linux_arm64.tar.gz.

Windows
PS> irm https://ptah.run/install.ps1 | iex

PowerShell ab Version 5.1. Installiert nach %LOCALAPPDATA%\Ptah\bin und aktualisiert den Benutzer-Path, sofern dies nicht deaktiviert wurde. Eine Version lässt sich mit $env:PTAH_INSTALL_VERSION = 'v0.3.0' festlegen.

Homebrew
$ brew install stokaro/ptah/ptah
# Entwicklungszweig, wird aus dem Quellcode gebaut
$ brew install --HEAD stokaro/ptah/ptah-edge

macOS oder Linux. Beide Formeln installieren Programme mit denselben Namen. Entfernen Sie die eine, bevor Sie zur anderen wechseln.

Go
$ go install ptah.run/cmd/ptah@v0.3.0
$ go install ptah.run/cmd/ptah-compat@v0.3.0
$ go install ptah.run/cmd/ptah-ls@v0.3.0

Die Programme landen in GOBIN oder, wenn nicht gesetzt, in $(go env GOPATH)/bin. Dieses Verzeichnis wird nicht automatisch zu PATH hinzugefügt.

Quellcode
$ git clone https://github.com/stokaro/ptah.git
$ cd ptah
$ make build

make build erzeugt ptah, ptah-compat, ptah-ls und den Integrationstest-Runner unter bin/. Dabei wird die in go.mod angegebene Toolchain verwendet.

Erwartete Ausgabe
ptah: sha256 verified against checksums.txt
ptah: installed ptah, ptah-compat, ptah-ls in <install directory>
Version: <installed version>

Die Zeile Version: stammt vom installierten Programm. Das Skript führt es aus, bevor es Erfolg meldet. Liegt das Ziel unter Linux oder macOS nicht in PATH, gibt das Skript export PATH="$HOME/.local/bin:$PATH" aus.

Prüfen
$ ptah version
$ ptah-compat version
$ ptah-ls --version

Jeder Befehl gibt Version, Commit, Build-Datum, Go-Toolchain und Plattform aus. ptah-compat verwendet den Befehl version statt des Flags --version.

Ein Release festlegeninstall.sh | sh -s -- --version v0.3.0
Signatur prüfenchecksums.txt ist mit Sigstore signiert. Prüfen Sie die Signatur mit cosign verify-blob oder übergeben Sie --verify-signature.
