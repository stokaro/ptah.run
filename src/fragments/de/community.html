Community

Ptah wird offen auf GitHub entwickelt. Fragen, Ideen, Fehlerberichte und Beiträge sind willkommen, unabhängig von Ihrer Erfahrung mit Datenbanken oder Go.

Für die Teilnahme gilt der Verhaltenskodex.

Eine Frage stellen

In GitHub Discussions können Sie Fragen zu ptah, ptah-compat oder der Go-Bibliothek stellen, erste Ideen besprechen und Projekte mit Ptah zeigen. Alle können mitlesen. Zum Schreiben ist ein GitHub-Konto erforderlich.

Die FAQ und die Fehlerdiagnose beantworten häufige Fragen. Suchen Sie deshalb zuerst in der Dokumentation. Markieren Sie eine hilfreiche Lösung als Antwort, damit andere sie finden.

In Q&A fragen → Diskussionen lesen

Einen Fehler melden

Fehler und Funktionswünsche gehören in den Issue-Tracker. Dort erhalten sie ein Label und eine verantwortliche Person. Die Formulare fragen nach dem genauen Befehl, der Ausgabe von ptah version, Datenbankmotor und Serverversion sowie einer möglichst kleinen Eingabe, die den Fehler reproduziert. Nennen Sie das verwendete Programm: ptah und ptah-compat haben bewusst unterschiedliche Befehlsstrukturen.

Probleme mit dem Kubernetes-Operator gehören zu stokaro/ptah-operator, Probleme mit dieser Website zu stokaro/ptah.run.

Ein Issue öffnen → Vorhandene Issues durchsuchen

Eine Sicherheitslücke melden

Melden Sie Sicherheitsprobleme vertraulich über das GitHub-Formular für Sicherheitsmeldungen, nicht in einem Issue oder einer Diskussion. Bis zur Veröffentlichung einer Sicherheitsmitteilung sehen nur Sie und die Maintainer den Bericht.

Mitwirken

Beiträge müssen kein Code sein. Ein minimales Reproduktionsbeispiel, eine Messung an einem echten Server, eine Dokumentationskorrektur oder eine Antwort in Discussions helfen ebenso. CONTRIBUTING.md beschreibt Vorschläge und erforderliche Prüfungen. AGENTS.md enthält die von CI-Prüfungen durchgesetzten Arbeitsregeln. Beide Dokumente sind auf Englisch.

Öffnen Sie vor einer Verhaltensänderung ein Issue, damit der Entwurf vor der Implementierung abgestimmt ist.

Repositories

Ptah umfasst mehrere Repositories in der Organisation stokaro. Jedes hat eigene Issues und Pull Requests.

stokaro/ptah
Die Programme ptah, ptah-compat und ptah-ls, die Go-Bibliothek und die englische Dokumentation auf docs.ptah.run.
stokaro/ptah-operator
Der Kubernetes-Operator. Seine englische Anleitung steht auf operator.ptah.run.
stokaro/ptah-action
Die GitHub Action: Migrationsplanung, Linting, Pull-Request-Kommentare und Prüfungen auf destruktive Änderungen.
stokaro/ptah-testkit
Testhilfen für Projekte, die Ptah einbetten, importiert als ptah.run/testkit.
stokaro/ptah-sandbox
Die Testumgebung: die zu WebAssembly kompilierte CLI mit einer echten SQLite-Datenbank im Browser.
stokaro/homebrew-ptah
Der Homebrew-Tap für brew install stokaro/ptah/ptah.
stokaro/ptah.run
Diese Website.

Geschäftliche Unterstützung

Geschäftliche Anfragen gehen per E-Mail an die in den FAQ genannte Adresse. Fehlerberichte und Funktionswünsche bleiben im öffentlichen Issue-Tracker.
