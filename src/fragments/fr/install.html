Installer Ptah

Le programme d’installation télécharge l’archive adaptée à votre système et à votre architecture, vérifie sa somme SHA-256 et installe ptah, ptah-compat et ptah-ls sans droits administrateur.

Version actuelle v0.3.0 · pre-GA : l’arborescence des commandes natives et l’API Go publique peuvent encore changer · MIT

macOS
$ curl -fsSL https://ptah.run/install.sh | sh

Installation dans ~/.local/bin. Nécessite un terminal, tar et curl. Homebrew convient aussi : brew install stokaro/ptah/ptah. Téléchargez les archives avec curl ou gh. Les téléchargements par navigateur portent un attribut de quarantaine qui conduit Gatekeeper à refuser les binaires signés ad hoc.

Linux
$ curl -fsSL https://ptah.run/install.sh | sh
# sans curl
$ wget -qO- https://ptah.run/install.sh | sh

Installation dans ~/.local/bin. Archives : ptah_0.3.0_linux_amd64.tar.gz, ptah_0.3.0_linux_arm64.tar.gz.

Windows
PS> irm https://ptah.run/install.ps1 | iex

PowerShell 5.1 ou ultérieur. Installation dans %LOCALAPPDATA%\Ptah\bin et mise à jour du Path utilisateur, sauf désactivation. Fixez une version avec $env:PTAH_INSTALL_VERSION = 'v0.3.0'.

Homebrew
$ brew install stokaro/ptah/ptah
# branche de développement, compilation des sources
$ brew install --HEAD stokaro/ptah/ptah-edge

macOS ou Linux. Les deux formules fournissent des binaires portant les mêmes noms. Désinstallez l’une avant de passer à l’autre.

Go
$ go install ptah.run/cmd/ptah@v0.3.0
$ go install ptah.run/cmd/ptah-compat@v0.3.0
$ go install ptah.run/cmd/ptah-ls@v0.3.0

Les binaires sont placés dans GOBIN, ou dans $(go env GOPATH)/bin si cette variable n’est pas définie. Ce répertoire n’est pas ajouté automatiquement au PATH.

Sources
$ git clone https://github.com/stokaro/ptah.git
$ cd ptah
$ make build

make build produit ptah, ptah-compat, ptah-ls et le lanceur de tests d’intégration dans bin/, avec la chaîne de compilation déclarée dans go.mod.

Sortie attendue
ptah: sha256 verified against checksums.txt
ptah: installed ptah, ptah-compat, ptah-ls in <install directory>
Version: <installed version>

La ligne Version: provient du binaire installé : le script l’exécute avant d’annoncer le succès. Sous Linux et macOS, si le répertoire cible n’est pas dans le PATH, le programme affiche export PATH="$HOME/.local/bin:$PATH".

Vérifier
$ ptah version
$ ptah-compat version
$ ptah-ls --version

Chaque commande affiche la version, le commit, la date de compilation, la chaîne Go et la plateforme. ptah-compat utilise la commande version plutôt que l’option --version.

Fixer une versioninstall.sh | sh -s -- --version v0.3.0
Vérifier la signaturechecksums.txt est signé avec Sigstore. Vérifiez la signature avec cosign verify-blob ou passez --verify-signature.
