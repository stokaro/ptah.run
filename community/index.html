Community

Ptah is built in the open on GitHub. Questions, ideas, bug reports and contributions are welcome from anyone, whatever your experience with databases or with Go.

Participation is covered by the Code of Conduct.

Ask a question

GitHub Discussions is the place to ask how to do something with ptah, ptah-compat or the Go library, to raise an idea that is not a concrete feature request yet, and to show what you have built with Ptah. Anyone can read it; posting needs a GitHub account.

The FAQ and the troubleshooting page answer the questions that come up most, so search the documentation first. When a reply solves your question, mark it as the answer so the next reader finds it.

Ask in Q&A → Browse Discussions

Report a bug

Bugs and feature requests go to the issue tracker, where each one gets a label and an owner. The forms ask for what makes a report actionable: the exact command, the output of ptah version, the engine and server version, and the smallest input that reproduces the problem. Say which binary you ran, because ptah and ptah-compat present different command surfaces on purpose.

A problem with the Kubernetes operator goes to stokaro/ptah-operator, and a problem with this website to stokaro/ptah.run.

Open an issue → Search existing issues

Report a vulnerability

Report a security problem privately, through the GitHub advisory form, and not in an issue or a discussion. Only you and the maintainers see the report until the maintainers publish an advisory.

Contribute

Code is one way to help. A reduced reproduction, a measurement against a real server, a correction to a page that is wrong, and an answer in Discussions help as much. CONTRIBUTING.md covers proposing a change and the checks it has to pass, and AGENTS.md holds the working rules the CI gates enforce.

Open an issue before a change that alters behavior, so the design is settled before the diff exists.

Repositories

Ptah is several repositories under the stokaro organization. Each one takes its own issues and pull requests.

stokaro/ptah
The ptah, ptah-compat and ptah-ls binaries, the Go library, and the documentation at docs.ptah.run.
stokaro/ptah-operator
The Kubernetes operator. Its guide is at operator.ptah.run.
stokaro/ptah-action
The GitHub Action: migration planning, linting, pull request comments and destructive-change checks.
stokaro/ptah-testkit
Test helpers for projects that embed Ptah, imported as ptah.run/testkit.
stokaro/ptah-sandbox
The Playground: the CLI compiled to WebAssembly, running against a real SQLite in the browser.
stokaro/homebrew-ptah
The Homebrew tap behind brew install stokaro/ptah/ptah.
stokaro/ptah.run
This website.

Commercial support

Commercial enquiries go by email; the address is in the FAQ. Keep bug reports and feature requests on the issue tracker, where they stay public.
